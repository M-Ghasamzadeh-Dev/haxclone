# HaxClone — نسخه‌ی آنلاین (ماژولار)

بازی فوتبال آنلاین شبیه HaxBall، با HTML/CSS/JS خالص (بدون فریم‌ورک) + PeerJS برای اتصال مستقیم P2P بین بازیکن‌ها.

## ساختار فایل‌ها (ماژولار)
```
index.html          صفحه‌ی اصلی و رابط کاربری
style.css           استایل‌ها
js/config.js        همه‌ی مقادیر قابل‌تنظیم (سرعت، قدرت شوت، ...) — اول اینجا رو نگاه کن
js/maps.js           تعریف نقشه‌های مختلف زمین (کلاسیک، بزرگ، کوچک، باریک)
js/physics.js         فیزیک بازی: حرکت، دریبل، برخورد، گل، کیک‌آف، پایان بازی
js/network.js          لایه‌ی شبکه (PeerJS): ساخت/ورود به اتاق، پروتکل پیام‌ها
js/render.js             رسم زمین/دروازه/بازیکن‌ها/توپ/تایمر/کیک‌آف/بنر پایان بازی
js/sound.js               افکت‌های صوتی (Web Audio API، بدون فایل خارجی)
js/chat.js                  نمایش پیام‌های چت
js/main.js                    اتصال‌دهنده‌ی همه‌چیز به هم (DOM ↔ physics ↔ network ↔ render ↔ sound)
```
هر بخش جداست، پس مثلاً اگه خواستی فقط قدرت شوت یا سایز زمین رو عوض کنی، فقط کافیه `js/config.js` یا `js/maps.js` رو باز کنی و عددش رو تغییر بدی — نیازی به دست‌زدن به بقیه‌ی کدها نیست.

## چیزهای جدید در این نسخه
1. **صدا** 🔊: افکت صوتی برای شوت، برخورد به دیوار، گل (ملودی کوتاه)، و سوت پایان بازی. کاملاً با Web Audio API ساخته شده، نیازی به فایل صوتی یا اینترنت نداره. یه دکمه‌ی 🔊/🔇 بالای صفحه‌ی بازی برای قطع/وصل صداست.
2. **دکمه‌ی «بازی جدید»**: وقتی مسابقه تموم بشه (برد یا مساوی)، یه نوار با دکمه‌ی «🔁 بازی جدید» بالای زمین ظاهر میشه. فقط هاست می‌تونه بزنه (بقیه پیام «منتظر بمون» می‌بینن). با زدنش امتیاز، تایمر و موقعیت‌ها کامل ریست میشه و بازی از نو شروع میشه.
3. **چند نوع زمین**: موقع ساخت اتاق از منوی کشویی «نوع زمین» یکی از این‌ها رو انتخاب کن:
   - کلاسیک (۹۰۰×۵۲۰)
   - زمین بزرگ (۱۱۰۰×۶۲۰) — فضای بیشتر، دروازه‌ی بزرگ‌تر
   - زمین کوچک/سریع (۷۰۰×۴۲۰) — بازی فشرده و سریع
   - زمین باریک/رفت‌وبرگشتی (۱۱۵۰×۴۲۰) — دروازه‌ی بزرگ، حمله برگشت سریع
4. **کیک‌آف واقعی بعد از گل**: بعد از هر گل، همه‌ی بازیکن‌ها به‌جای اول خودشون برمی‌گردن، توپ میره وسط زمین، و یه مکث ۱.۵ ثانیه‌ای (با شمارش معکوس روی زمین) قبل از آزاد شدن توپ وجود داره تا هیچ تیمی مزیت ناعادلانه نداشته باشه.

## دریبل و فیزیک توپ (از نسخه‌ی قبل)
توپ نزدیک بازیکن که بشه می‌چسبه بهش (حلقه‌ی زرد نشونش میده)، فقط با **Space** با قدرت زیاد شوت میشه. توپ آزاد خیلی کند نمیشه (اصطکاک کمه) پس کنترل دقیقش سخته.

## تنظیمات اتاق (موقع Host کردن)
- ظرفیت هر تیم (پر که بشه بازیکن جدید نمی‌تونه اون تیم رو انتخاب کنه)
- مدت بازی به دقیقه (۰ = نامحدود)
- امتیاز برد (۰ = نامحدود)
- **قانون ترکیبی**: مثلاً ۱۴ دقیقه + امتیاز برد ۶ گل → هرکدوم زودتر برسه بازی همون‌جا تموم میشه؛ اگه زمان تموم شد و هیچ‌کدوم نرسید، امتیاز بیشتر برنده‌ست، مساوی بودن = مساوی.

## کنترل‌ها
- حرکت: کلیدهای جهت‌دار
- گرفتن/چسباندن توپ: خودکاره (فقط نزدیکش شو)
- شوت (رها کردن توپ با قدرت): Space

## چطور تست کنم قبل از آپلود؟
چون فایل‌ها از `type="module"` استفاده می‌کنن، مرورگرها با باز کردن مستقیم فایل (دابل‌کلیک روی index.html) به‌خاطر محدودیت CORS اجازه‌ی اجرا نمیدن. برای تست محلی:
```
cd پوشه‌ی-پروژه
python3 -m http.server 8000
```
بعد `http://localhost:8000` رو تو مرورگر باز کن. روی خود GitHub Pages (چون از https سرو میشه) این مشکل اصلاً پیش نمیاد.

## آپلود روی GitHub Pages
1. یه ریپازیتوری جدید بساز (مثلاً `haxclone`).
2. کل محتوای این پوشه (`index.html`, `style.css`, پوشه‌ی `js/`) رو با همین ساختار آپلود کن — می‌تونی کل پوشه رو با درگ‌اند‌دراپ تو صفحه‌ی "Add file → Upload files" بریزی، گیت‌هاب ساختار پوشه‌ها رو حفظ می‌کنه.
3. برو **Settings → Pages**، تو بخش Source بذار **Deploy from a branch**، شاخه `main` و پوشه `/ (root)`، بعد Save.
4. چند ثانیه بعد لینکی شبیه `https://username.github.io/haxclone/` بهت میده.
5. اون لینک رو باز کن، اسم و تیمت رو انتخاب کن، اتاق بساز (یا با کد وارد اتاق دوستت شو) و بازی کن.

## نکات فنی
- هاست (کسی که اتاق می‌سازه) باید تبش رو باز نگه داره تا بازی ادامه پیدا کنه (محدودیت ذاتی P2P، دقیقاً مثل خود HaxBall).
- از سرور رایگان عمومی PeerJS فقط برای برقراری اولیه‌ی اتصال (signaling) استفاده میشه؛ خودِ بازی و فیزیک مستقیم بین مرورگرها رد و بدل میشه.
- پشت فایروال‌های خیلی سخت‌گیر ممکنه گاهی اتصال مستقیم برقرار نشه (بدون TURN سرور اختصاصی).

## بعداً می‌خوای چی اضافه/عوض کنی؟
با این ساختار ماژولار:
- تغییر فیزیک/سرعت/قدرت شوت → فقط `config.js`
- تغییر ظاهر زمین/رنگ‌ها → فقط `render.js`
- تغییر پروتکل شبکه یا رفتار اتصال → فقط `network.js`
- اضافه‌کردن قانون جدید بازی (مثلاً پنالتی، آفساید) → `physics.js`
- اضافه‌کردن نقشه‌ی جدید → فقط `maps.js`
- عوض کردن صداها → فقط `sound.js`
